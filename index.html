Connect Supabase

This app is ready for online sharing. Add your Supabase Project URL and Publishable Key in config.js, then reload.

  1. Create a free Supabase project.
  2. Run supabase_setup.sql in the Supabase SQL Editor.
  3. Copy your Project URL and Publishable Key into config.js.
  4. Upload these files to your website/hosting.
